# E-Commerce Automation System

## Project Overview

The **E-Commerce Automation System** is a Salesforce-based application developed using **Lightning Web Components (LWC), Apex, SOQL, and Salesforce Custom Objects**.

The application follows a component-based architecture to manage the complete E-Commerce workflow, including product listing, product details, shopping cart management, and checkout.

---

## Technology Stack

- Salesforce
- Lightning Web Components (LWC)
- Apex
- SOQL
- Salesforce Custom Objects
- Lightning Data Service (LDS)
- Lightning App Builder
- Visual Studio Code
- Salesforce CLI

---
