# E-Commerce Automation System

## Project Overview

A Salesforce-based E-Commerce application built using **Lightning Web Components (LWC), Apex, SOQL, and Salesforce Custom Objects**.

The application provides an end-to-end E-Commerce workflow where users can browse products, view product details, add products to a shopping cart, manage quantities, and proceed to checkout.

---

## Features

- Product browsing
- Product details
- Add to Cart
- Shopping cart management
- Quantity management
- Checkout
- Customer information validation
- Order creation
- Stock validation
- Salesforce data management
- Reusable Lightning Web Components
- Parent-to-Child communication
- Child-to-Parent communication
- Custom Events
- Lightning Data Service
- Wire Service
- Imperative Apex
- Client-side and server-side validation
